## Two defects found while grounding the procedure

- **Cosmetic:** the apt repository-deletion group title is `Delete repositorys the source no longer has (apt)` — `_REPO_REMOVAL_VERBS` supplies "delete repository" and `_build_review_groups` appends `"s"`. The pin group reads correctly. Noted in the runbook as an observation, not a failure.
- **Behavioural, worth an issue:** answering **Skip** at the collateral prompt writes `SKIP_ONCE` over *every* package in the batched removal (or install) candidate set, not only the ones that produced the collateral — `_classify_collateral` passes the whole candidate set as `trigger_ids`. Since `_record_permanent_skips` runs on the post-override decision map, a "Skip" silently cancels a never-offer-again tick the user made on an unrelated removal in the same review. The runbook's answer plan works around it and tells the user to record the erasure.
