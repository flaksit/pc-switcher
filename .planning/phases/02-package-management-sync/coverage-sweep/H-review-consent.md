# Sweep — H: consent, the review, the answers, and the memory of a decision

Articles: `PKG-FR-REVIEW-FIRST`, `PKG-FR-ONLY-APPROVED`, `PKG-FR-BATCHED`, `PKG-FR-ASK-AGAIN`, `PKG-FR-CONSENT-BEFORE-CHANGE`, `PKG-FR-ASK-ABOUT-SOFTWARE`, `PKG-FR-ASK-WHEN-NOT-DERIVABLE`, `PKG-FR-NAME-THE-MACHINES`, `PKG-FR-EFFECT-NOT-MECHANISM`, `PKG-FR-ANSWERS-AS-A-SET`, `PKG-FR-REMOVAL-DISTINCT`, `PKG-FR-HARMLESS-DEFAULT`, `PKG-FR-SKIP-ONCE`, `PKG-FR-MACHINE-SPECIFIC`, `PKG-FR-NO-MARK-ON-ORIGIN`, `PKG-FR-NO-MARK-ON-REPORT`, `PKG-FR-ABORT`, `PKG-NG-MARK-ORIGIN`, `PKG-NG-MARK-PORTABILITY`, `PKG-NG-UNATTENDED`, `PKG-NG-AUTOMATION-ENV`.

Machines: **Atlas** (source), **Nomad** (target), **Vega** (a third machine).

Test paths: `tests/unit/jobs/` unless prefixed `integration:` (= `tests/integration/jobs/test_package_sync.py`). Module names are given without `test_` where unambiguous — e.g. `package_review:TestInteractive::test_x` is `tests/unit/jobs/test_package_review.py`.
